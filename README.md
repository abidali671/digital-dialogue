# Digital Dialogue

Next.js App Router blog powered by Contentful.

## Niche

Practical Upwork guides for freelance web developers.

One subject for the whole site. Each post targets one keyword inside that subject, such as an Upwork proposal, profile, fee, or first job. The audience is global.

## Getting started

```bash
npm install
cp .env.example .env
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### Environment variables

Copy `.env.example` and fill in:

| Variable | Purpose |
|---|---|
| `CONTENTFUL_DELIVERY_ACCESS_TOKEN` | Contentful Delivery API token |
| `CONTENTFUL_SPACE_ID` | Contentful space ID |
| `CONTENTFUL_ENVIRONMENT` | Usually `master` |
| `REVALIDATE_SECRET` | Secret for on-demand cache clear (`/api/revalidate`) |

Also set these in the Vercel project for production.

Sitemap and robots are generated by the App Router (`/sitemap.xml`, `/robots.txt`) from Contentful posts, categories, and authors.

## Clear cache (`/api/revalidate`)

Protected by `REVALIDATE_SECRET`. POST only, with `Authorization: Bearer …`.

- **Full site:** clears the Contentful data cache tag, static routes, and every blog/category path
- **Single path:** POST a JSON body `{ "path": "/blogs/category/slug" }`. That clears the Contentful data cache tag **and** that route

Replace:

- `YOUR_DOMAIN` → `http://localhost:3000` locally, or `https://www.digitaldialogue.pk` in production
- `YOUR_SECRET` → value of `REVALIDATE_SECRET`

### POST

```bash
curl -X POST "https://www.digitaldialogue.pk/api/revalidate" \
  -H "Authorization: Bearer YOUR_SECRET"
```

Single page:

```bash
curl -X POST "https://www.digitaldialogue.pk/api/revalidate" \
  -H "Authorization: Bearer YOUR_SECRET" \
  -H "Content-Type: application/json" \
  -d '{"path":"/blogs"}'
```

Successful response:

```json
{
  "revalidated": true,
  "now": 1710000000000,
  "scope": "all",
  "tag": "contentful",
  "paths": ["/", "/blogs", "/authors", "/about", "/contact-us", "/privacy-policy", "/disclaimer", "/feed.xml"]
}
```
